# Industrial Training Project

## 📌 Project Overview

This project was developed as part of my **Industrial Training** to apply and strengthen my practical knowledge of web development.

It is a responsive web-based project built using fundamental front-end technologies, with separate pages for the main interface, contact section, and login functionality.

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and layout
* **JavaScript** – Interactivity and functionality

## ✨ Features

* 🏠 Home page
* 🔐 Login page
* 📩 Contact page
* 🎨 Custom CSS styling
* ⚡ JavaScript-based functionality
* 📱 User-friendly web interface

## 📂 Project Structure

```text
industrial-training-project/
│
├── index.html
├── contact.html
├── login.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the different pages using the navigation options.
